# MediCart - An Online Medical Shop

## Project Description
MediCart is a full-stack web application that allows users to browse and purchase medicines online while managing healthcare needs.

## Features
- User authentication with OTP verification  
- Secure login and registration system  
- Product listing and cart functionality  
- Healthcare chatbot (AI-based)  
- Prescription upload feature
- Reminders to take medicines on time
  
## Tech Stack
- Frontend: HTML, CSS, JavaScript  
- Backend: Node.js, Express.js  
- Database: MongoDB  

## How to Run
1. Clone the repository  
2. Run `npm install`  
3. Start server using `node server.js`  
4. Open browser and visit `localhost:3000`
